What your client sees

Open the laptop.
Everything's still there.

When you attach, you get the welcome burst, your channels with their topics, the backlog with original timestamps, and then live traffic.

  • server-time and echo-message for clients that support them
  • Channel events replayed from *buffextras, so your nick list stays correct
  • Optional: only replay what arrived since you were last attached
How it works

Every channel stays joined, and every line is saved.

evrd keeps one permanent connection to each network, stays in your channels and counts what's waiting for you. This is the same view as the web app's overview.

Features

A bouncer for everyone from one person to a whole community.

Run a single node with a file on disk, or a cluster behind a load balancer that serves a whole community. Either way, the settings are the ones ZNC users already know.

Backlog you can trust

Messages, joins, parts, quits, kicks, nick changes, topics and modes are saved, and replayed to every client with server-time. Channel events come from *buffextras as plain text, so they never confuse your client's nick list. Playback can be limited to what arrived since you were last attached.

Kept per channel (default)2,000 lines

Any IRC client

Attach with a server password user/network:pass. Native clients get the welcome burst, names, topics, backlog and a full-fidelity live feed.

Clients per user (default)unlimited

A real web client

Svelte web app with unread counts, mentions, members, topics and slash commands (/join, /msg, /me, /quote and more), kept in sync with your other clients.

Mentions badge3

ZNC-style *status

/msg *status help to add networks, jump between them, play back a buffer or change settings. ZNC's command names work too.

playback default / max50 / 500 lines

Scales out

Run any number of nodes against the same Postgres and ScyllaDB. If a node dies, its users move to the others in about 20 seconds.

cluster_lease20 s

SSO or passwords

Local passwords, OpenID Connect (Logto or any OIDC provider), or both. Per-client IRC passwords can be revoked one at a time.

session_ttl (default)720 h

Secrets stay secret

Network passwords are encrypted with AES-256-GCM under a key that lives outside the database, and keys can be rotated. Account passwords are bcrypt hashes.

CipherAES-256-GCM

Observable

Exports OpenTelemetry metrics over OTLP, covering lines, lag, disconnects and clients, and draws the dashboard traffic chart from VictoriaMetrics.

otel_interval15 s

Built for hosting others

Roles, per-user limits, suspension, bind hosts and per-user IPv6 addresses. Admins can edit most of evrd.conf from the web app.

connect_rate (example)5 / s
Muscle memory included

Talk to the bouncer from any client.

Everything the web app does, *status does too, so a terminal client is all you need. Coming from ZNC? AddTrustedServerFingerprint and friends still work.

  • Add, connect and remove networks without leaving your client
  • Replay up to 500 lines of any buffer on demand
  • Manage servers, certificate fingerprints, flood and encoding settings

Self-hosted

One config file.
One binary per node.

The config is a few readable directives. Start with SQLite and an embedded Pebble store on one machine, then move to Postgres and ScyllaDB when you outgrow it. evrctl history copy moves your history across.

  • The database backend is picked from the DSN, with no code changes
  • Pure Go, statically built, multi-arch images
  • evrctl for admin from a shell
